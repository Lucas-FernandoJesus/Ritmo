Estas fichas preservam uma observação individual por **vídeo distinto**. Foram produzidas a partir de transcrições/legendas examinadas ao longo de cada aula; não são transcrições integrais nem confirmação visual de cada gesto. “Uso” indica uma decisão de planejamento do Ritmo, **não** uma recomendação literal do instrutor. Posições repetidas aparecem juntas; o link é sempre da URL individual.
