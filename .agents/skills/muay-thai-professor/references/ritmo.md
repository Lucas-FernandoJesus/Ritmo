# Aplicação no Ritmo

Este contexto vale quando a pasta atual é o repositório Ritmo. Leia as versões atuais antes de agir: `AGENTS.md`, `docs/rotina/03_treino_muay_thai_matinal.txt`, `docs/muay-thai/pesquisa-e-plano.md`, `docs/muay-thai/inventario.md`, `docs/muay-thai/fichas.md` e `docs/muay-thai/transcricoes/README.md`. Para sessões implementadas, consulte `app-rotina/src/features/training/training-plan.ts` e `muay-exercises.ts`.

O objetivo do treino matinal é técnica, movimentação, condicionamento moderado e regularidade em até 20 minutos no começo, segunda e quarta, com sexta opcional conforme recuperação. O usuário informou alta para exercícios em fevereiro de 2026 e confirmou depois que ela abrange todas as modalidades, sem restrição específica. Impacto e potência do braço esquerdo devem progredir gradualmente; dor nova, crescente ou persistente é o principal sinal para interromper ou regredir. Permanecem dois fios de Kirschner no braço esquerdo e, segundo o usuário, a retirada ficou a seu critério. Registre isso como relato do usuário, sem interpretar o material, sugerir retirada ou usar o treino como teste de tolerância.

O projeto tem plano de 24 semanas, blocos e rounds próprios. O documento matinal e o código podem representar estágios diferentes do planejamento; para uma resposta sobre o app, verifique o plano implementado e explique diferenças relevantes. Não invente histórico, domínio de habilidade, métricas ou liberação. Use as doses do plano em vigor, não as durações das aulas do YouTube. A quarta semana de cada bloco é de consolidação; a conclusão da sessão não equivale a domínio técnico.

O acervo registra 127 vídeos utilizáveis, todos com legendas originais salvas. Procure pelo ID no manifesto e leia apenas as transcrições relevantes para o pedido. Use `fichas.md` para triagem, confirme o trecho no arquivo do vídeo antes de uma citação precisa e faça ressalva quando o detalhe exigir conferência visual. Links de vídeo exigem rede; as instruções essenciais do app permanecem offline.

Ao propor mudança no Ritmo, siga `AGENTS.md`: tarefas ordenadas, testes relacionados e build; preserve dados offline/IndexedDB e peça autorização antes de alterar arquitetura, dados ou dependências. A skill é guia pedagógico; não cria permissão para modificar o aplicativo.
